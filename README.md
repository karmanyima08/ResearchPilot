# ResearchPilot

An AI-powered research assistant for academic literature analysis.

## Tech Stack

- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- Vector Database: ChromaDB
- AI: Gemini
- Parser: Docling

## Current Progress

- ✅ FastAPI Backend
- ✅ File Upload
- ✅ Document Storage
